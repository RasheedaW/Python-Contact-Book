\# Python Essentials 1 - Contact Book SBA



\## About My Project



I created a Contact Book using Python. The program lets users add, view, search, and delete contacts. It also checks for duplicate names and invalid inputs.



\## How It Works



I used a dictionary to store names and phone numbers. I created separate functions for adding, viewing, searching, and deleting contacts.



I used a while loop to keep the menu running, if/else statements for choices, and try/except to handle errors.
